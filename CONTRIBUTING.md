# Contributing

This repository is primarily a personal EPAT project and public portfolio artifact.

External pull requests are not accepted by default.

Do not submit code, strategy logic, data, model outputs, broker integrations, or trading rules unless explicitly requested by Daksh Goyal.

If contributions are accepted in the future, contributors must confirm that:

1. they have the right to submit the contribution;
2. the contribution does not contain confidential, proprietary, broker-sensitive, or third-party restricted material;
3. the contribution may be licensed under the repository license terms;
4. the contribution does not create any obligation to open-source, commercialize, or redistribute the project.
