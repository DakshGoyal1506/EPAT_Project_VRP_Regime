# Artifact Documentation

This folder contains per-phase documentation for generated artifacts.

Generated artifacts are local-only by default. Commit source code, configs, scripts, tests, docs, README files, and `.gitkeep` placeholders. Do not commit generated data panels, model binaries, report tables, report figures, broker cache, or logs unless explicitly approved as final-report artifacts.
